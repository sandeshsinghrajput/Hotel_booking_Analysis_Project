# Hotel_booking_Analysis_Project
#Project Overview  : 
In recent years, the hotel industries have seen high cancellation rates. Hotels are now dealing with a number of issues as a result, including fewer revenues and less than ideal hotel room use. Consequently, lowering cancellation rate is hotel's primary goal in order to increase their efficiency in genearting revenue. 
Analysis of hotel booking cancellation and solution to their problem are the main topics of this project
